# ADR-0002: 自用MVPを区切り後に独立プロジェクトへ切り出す

- 日付: 2026-09-21
- 状態: 採択
- 決定者: yo-xe + Claude Code

## 背景

`docs/QUESTIONS.md` Q-0001(2026-09-20)で、自用private MVPの継続・凍結判断基準が
既存成果物から確定できないと記録していた。盲点監査(Phase 0〜6)は継続中で、
`jev-exp`からsubmoduleとしてcommit固定する現行構成のまま進めるか、yo-xeの判断が必要だった。

## 決定

yo-xeが2026-09-21に回答: MVPは継続する。現在計画中の内容(盲点監査Phase 5・6等)は
「MVP」の範囲としてこのまま`jev-exp`のsubmoduleで続けてよい。ただし区切りの良い
ところ(盲点監査の一区切り等)まで進めたら、`jev-exp`から完全に独立した別プロジェクトへ
切り出す。`origin`(`yo-xe/jev-ultrafast-private`)は既にjev-exp外の独立repoなので、
切り出し自体はsubmodule参照の解消(`jev-exp`側の`vendor/jev-ultrafast`除去)が主作業になる
見込み。

## 検討した代替案(没案)

- 利用実績・比較実験への寄与・保守費用で継続/凍結の数値基準を事前に定める(Q-0001の推奨案):
  yo-xeは具体的な基準策定より先に「継続+将来分離」という方向性そのものを回答したため、
  この案は採らなかった。数値基準が必要になれば別途検討する。
- 当面は基準を設けない(Q-0001のもう一つの選択肢): 同様に、方向性が既に決まったため
  未採用。

## 影響

- 当面(区切りまで)は現行のsubmodule構成・commit固定運用を変更しない。
- 切り出しのタイミングと具体的な手順(独立repoとしてのCLAUDE.md/STATUS再構築、
  `jev-exp`側submodule参照の除去方法)は未確定。区切りが近づいた時点で別途決める。
